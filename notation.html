Notation & Glossary

One symbol means one thing in this course. This page lists every symbol and the key words. Keep it open in a second tab while you read.

1How we write things

Written asMeansExample
$x$, $w$, $\alpha$A single number (a scalar). Italic, lowercase.$w = 0.5$
$\mathbf{x}$, $\mathbf{b}$A vector (a list of numbers). Bold, lowercase.$\mathbf{x} = [2, 1, 3]$
$\mathbf{W}$, $\mathbf{X}$A matrix (a grid of numbers). Bold, uppercase.$\mathbf{W} \in \mathbb{R}^{2\times 3}$
$x_i$, $W_{ij}$One entry: slot $i$ of a vector, row $i$ and column $j$ of a matrix.$x_2 = 1$
$\mathbb{R}^n$The set of all lists of $n$ real numbers.$\mathbf{x} \in \mathbb{R}^3$
$\mathbf{W}^\top$Transpose: rows become columns.$(2\times 3)^\top \to (3\times 2)$
$\mathbf{a}\cdot\mathbf{b}$Dot product: multiply matching slots, then add.$[1,2]\cdot[3,4] = 11$
$\odot$Element-wise product: multiply matching slots, keep them separate.$[1,2]\odot[3,4] = [3,8]$
$\lVert\mathbf{x}\rVert$Norm: the length of a vector (L2 unless we say L1).$\lVert[3,4]\rVert = 5$
$\sum_{i=1}^{n}$Add up the terms as $i$ counts from 1 to $n$.$\sum_{i=1}^{3} i = 6$
$\hat{y}$“y-hat”: a prediction of $y$.$\hat{y} = 0.8$
$\log$, $\ln$, $\log_2$$\ln$ and $\log$ are the natural log (base $e$). $\log_2$ is base 2 (bits).$\log_2 8 = 3$

2Calculus and probability

SymbolMeans
$\frac{dy}{dx}$Derivative: how fast $y$ changes when $x$ changes a little.
$\frac{\partial L}{\partial w}$Partial derivative: change $w$ only, keep every other input fixed.
$\nabla L$Gradient: the vector of all partial derivatives. It points uphill.
$P(A)$, $P(A \mid B)$Probability of $A$; probability of $A$ when we know that $B$ is true.
$\mathbb{E}[X]$Expected value: the long-run average of $X$.
$\mu$, $\sigma$, $\sigma^2$Mean, standard deviation, variance.
$H(p)$, $H(p,q)$, $D_{\text{KL}}(p\,\Vert\,q)$Entropy, cross-entropy, KL divergence (Section 4).

4Glossary

Short, plain definitions. Each lesson explains the word in full the first time it appears.

Activation function
A simple non-straight function (ReLU, sigmoid, tanh) applied after a layer. Without it, many layers act like one layer.
Attention
A layer where each token decides how much to use every other token, by comparing its query with their keys.
Autograd
PyTorch's automatic backpropagation: it records the operations and computes all gradients for you.
Backpropagation
The chain rule, applied backward through a computation graph, to get every gradient in one pass.
Batch
A group of examples processed together in one step.
Bias (of a layer)
The number (or vector) added after the weighted sum. Not the same as “bias” in bias–variance.
Bias–variance
Two kinds of error: bias (the model is too simple) and variance (the model changes too much with the data).
Computation graph
A diagram of every operation from inputs to loss. Backpropagation walks it backward.
Convex
Bowl-shaped: any local minimum is also the lowest point.
Cross-entropy
The usual loss for classification: the average surprise of the model at the true labels.
Embedding
A learned vector that stands for a token (or another discrete thing).
Epoch
One full pass through the training data.
Equivariance
When the input moves, the output moves in the same way. (Invariance: the output does not change.)
Gradient descent
Repeat: compute the gradient of the loss, take a small step the other way.
Hyperparameter
A setting you choose (learning rate, batch size), not a number the model learns.
Logit
A raw score before softmax or sigmoid. For two classes it is the log-odds.
Loss
One number that measures how wrong the model is. Training makes it smaller.
Mixture of experts (MoE)
A layer with many small networks (experts); a router sends each token to only a few of them.
Overfitting
The model learns the noise in the training data, so it does worse on new data.
Parameter
A number the model learns (a weight or a bias).
Regularization
Any method that keeps a model simpler so that it generalizes better (L1, L2, dropout, early stopping).
Softmax
Turns a list of scores into probabilities: make each one positive with $e^{z}$, then divide by the total.
Tensor
An array with any number of dimensions: a number, a vector, a matrix, or more.
Token
A piece of text (a word, part of a word, or a character) that the model reads as one unit.
Transformer
A network made of blocks of attention and feed-forward layers, with residual connections and normalization.
